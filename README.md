# Ventor — Signature-Only Open Source

Ventor is an open-source local AI runtime with Qwen + Gemma mentor cores, adaptive routing, memory, and hardware-aware execution.

Ventor has no Owner Gate or application login. Documents and release artifacts can carry detached Ed25519 signatures containing creator identity, public-key fingerprint, SHA-256 digest, timestamp, type, metadata, and signature. The private signing key is never committed.

Signature provenance is not authorization. High-risk host actions remain sandboxed and require explicit confirmation.
